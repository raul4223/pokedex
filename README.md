# Pokédex

Uma aplicação de Pokédex simples e moderna construída com [Angular](https://angular.dev/) que consome a [PokéAPI](https://pokeapi.co/).

## 🚀 Funcionalidades

- Listagem de Pokémon
- Busca por nome ou ID
- Visualização de detalhes (tipo, estatísticas, etc.)

## 🛠️ Tecnologias

- **Framework:** Angular 21
- **Estilização:** CSS
- **API:** PokéAPI

## 📦 Como rodar o projeto

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```

3. Abra o navegador em `http://localhost:4200/`.
